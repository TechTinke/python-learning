## V8 ENGINE

-> JS Engine that is used by Node JS

1. Parse Javascript -> Creates an internal representation of your code -> Producing byte code then it is going to -> Execute the code then -> 2. Manage Call Stack
2. Manage Heap Memory
3. Perform garbage collection

-> **Parser** - create an internal representation of your code to produce byte code
-> **Abstract Syntax Tree** - understanding the structure and the meaning of the program
-> **Byte Code**/ **Interpreter**- low level format that is easier to understand by the V8 engine
-> **Interpreter**
-> **Optimized Machine Code** - optimize your code
-> **Code Execution**
